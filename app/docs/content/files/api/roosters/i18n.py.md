The only texts the **server** writes: error messages, in Dutch and English (the e-mails are in `mails.py`, and the push
texts which are in `push.py`: they're written while the app isn't running). All screen text lives in the app
(`mobile/src/i18n/`), which receives codes, not sentences (statuses, notifications).

Dutch is the default (the first schools are Flemish); English is for international students.

## `ERRORS`

code → (Dutch, English). Every `ApiError` code should be here.

The `break_*` codes belong to break requests (`breaks.py`); `break_busy` and `break_dup` carry extra fields
the app turns into its own sentence (who can't, who asked first). The `chat_*` codes belong to chat (`chat.py`), `access_has` / `access_dup` to access requests (`access.py`), `skip_ask_dup` / `skip_ask_nothing` to skip questions (`skipasks.py`).

## `LANGS`

Supported languages; the `users.locale` column has the same two values.

## `error`

The message for a code in a language (an unknown code gives the generic server error text).

## `lang_of`

Picks the language from `Accept-Language`: Dutch for Dutch speakers and when unknown, English for everyone else.
