Dependencies and scripts of the app (Expo SDK 58, React Native 0.88, React 19.3, Expo Router, TanStack Query with an AsyncStorage persister, Uniwind for Tailwind classes, Reanimated + Worklets and Gesture Handler for motion and drags, expo-notifications for push, react-native-nitro-google-signin + react-native-nitro-modules for Sign in with Google; adding or upgrading those native modules needs a new development build; expo-dev-client makes that build a real dev client, and without it `expo start` warns "Unable to determine the default URI scheme for deep linking" and the QR code / `s` switch can't open the app, adding it needs a new development build too). `npm start` runs Expo; `npm run export:web` builds the web version (only used for testing and CI). Add packages with `npx expo install` so versions match the SDK. Needs Node 22.13+ (SDK 58). Upgrade the SDK with `./upgrade-sdk.sh`, never by editing versions here (recipe **Upgrading the Expo SDK**). Gesture Handler 3 marks the `Gesture.*` builder API the timetable and sheets use as deprecated: it still works, moving to its hook API (`usePanGesture`, …) is a later job.
