Dependencies and scripts of the app (Expo SDK 57, React Native 0.86, Expo Router, TanStack Query with an AsyncStorage persister, Uniwind for Tailwind classes). `npm start` runs Expo; `npm run export:web` builds the web version (only used for testing and CI). Add packages with `npx expo install` so versions match the SDK.
