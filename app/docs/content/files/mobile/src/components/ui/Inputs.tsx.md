Form controls in the design system.

## `CodeInput`

Six boxes for the e-mail code, with one hidden TextInput behind them, so paste and the phone's 'code from mail' autofill work like in a normal field. The box width comes from the **measured row** (at most 52 px each); flex alone left the boxes 0 wide.

## `InputProps`, `Input`

A labelled text field: 52 high, blue border when focused, red with a message on error.

## `Toggle`

An iOS-style switch in brand colours.
