Access requests ("Mag ik je rooster zien?", `roosters/access.py`): the levels, asking and accepting (the card in
the direct chat, the "Verzoek" count for both, the notification with its chat, `access_dup` and `access_has`, only
the one asked can accept, what they show you changes), declining and cancelling (only by the right person, only
friends), and unfriending (open ones cancelled), the export and account deletion.

## `_pair`

Reda and Kayra, friends; Kayra shows Reda only free/busy.

## `_ask`, `_shows`

Ask a friend for a level; what a friend shows you now (from `GET /friends`).
