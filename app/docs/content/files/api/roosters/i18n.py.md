The only texts the **server** writes: error messages and the login mail, in Dutch and English. All
screen text lives in the app (`mobile/src/i18n/`), which receives codes, not sentences (statuses,
notifications).

Dutch is the default (the first schools are Flemish); English is for international students.

## `ERRORS`

code → (Dutch, English). Every `ApiError` code should be here.

The `break_*` codes belong to break requests (`breaks.py`); `break_busy` and `break_dup` carry extra fields
the app turns into its own sentence (who can't, who asked first).

## `LANGS`

Supported languages; the `users.locale` column has the same two values.

## `error`

The message for a code in a language (an unknown code gives the generic server error text).

## `lang_of`

Picks the language from `Accept-Language`: Dutch for Dutch speakers and when unknown, English for everyone else.

## `login_mail`

Subject and body of the mail with the 6-digit code, with the code spaced as `123 456` (easier to read and type).
