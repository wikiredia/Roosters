**Dutch texts: the source of truth for keys.** Short, plain sentences; say 'je', never 'u'. Grouped by screen (`welcome.`, `login.`, `school.`, `steps.` for Today's 'complete these steps', …).

## `Key`

The union of all keys (other languages must have every one).

## `nl`

All Dutch texts. Pinned friends: `friends.pinned` / `friends.others` (the friends list's cards), `friend.pin*` and
`friend.pinned` (the toggle, the thumbtack's labels, the marker).

## `nlOne`

Singular forms for `n = 1` ('1 klas').
