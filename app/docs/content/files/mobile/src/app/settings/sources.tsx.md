## `AddLinkSheet`

Paste an iCal link (https or webcal) and an optional name.

The list, a banner when a source fails, retry. With any source, a **Class details** row opens the onboarding step that
sets how a lesson's details are shown (`app/onboarding/details.tsx?from=settings`).
