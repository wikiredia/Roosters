**Push notifications** (`push.py`): where to send them, what you want them for, and the bell per chat.

## `sessions (alter at line 4)`

`push_token` (+ `push_token_at`): the Expo push token of the phone this session is on, from `PUT /me/push-token`.
On the session on purpose: signing out, "log out everywhere", a revoked or expired session and account deletion stop
push to that phone without anything else to clean up. One token is on one session at a time (`push.register` takes
it off any other session: someone else signed in on that phone before). `k_push` finds it again when Expo says a
phone is gone (`push.forget`).

## `push_settings`

Meldingen, one row per user, made on the first change (no row = `push.DEFAULTS`: everything on, no quiet hours).
`requests`, `changes`, `chat`: the categories (also the Android channels). `quiet_from`/`quiet_until`: minutes
since midnight in the school's timezone, both or neither; from > until runs past midnight. Deleted with the account
(`accounts._OWNED`).

## `chat_members (alter at line 22)`

`push`: the bell of this chat, only for you; off by default so a busy group doesn't buzz all day.
