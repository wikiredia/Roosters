The settings template: `cp .env.example .env`. It works as-is on the laptop; **on a server every secret
must be new** (`python3 -c "import secrets; print(secrets.token_urlsafe(48))"`). `.env` itself is never
committed and never enters the docs container.

What each value does: `api/roosters/config.py`. `GOOGLE_CLIENT_IDS` gets the **web** OAuth client id that the app also
has as `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID` (the ID token's audience; guide **Running and operating** → Sign in with Google). Tokens for the management console: `ADMIN_TOKEN` (admin
API) and `DOCS_TOKEN` (writing docs), 32+ characters each.
