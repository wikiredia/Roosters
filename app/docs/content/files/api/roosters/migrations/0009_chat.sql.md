The chat tables (`chat.py`). Messages are kept until someone deletes their account (or a moderator removes one);
`chat_reports` keeps what was written even when the message is gone later.

## `chats`

One row per chat. `direct_key` (`'smaller:bigger'`, unique) for one-to-one chats, NULL for groups;
`last_message_id` so the list sorts without scanning messages.

## `chat_members`

Who is in a chat, `last_read_id` (unread counts, "gelezen") and `pinned` (only for that person). Leaving deletes
the row.

## `chat_messages`

`kind` text (with `user_id`) or event (`payload`, no writer). `deleted_at` + empty `body`: taken back, or
`removed=1`: removed by a moderator. `created_at` with milliseconds.

## `chat_reports`

"Meld dit bericht": message, reporter, writer, reason, note, `snapshot`; once per reporter and message.
`handled_at`/`handled_by`/`outcome` (dismissed, removed, disabled) from the admin API.
