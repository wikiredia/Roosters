Skipping a class through the API: a double period skipped in one call frees the time for you and for a friend (a
shared break appears on both sides, the friend never sees it was skipped), Undo makes you busy again, only your own
lessons from today on can be skipped, and skips are exported and deleted with the account.

## `DAY`, `H`, `_setup`, `_week`

Tomorrow (never "already over"), minutes per hour, Reda with a DevOps double period and Kayra free then (friends,
same campus), and a helper that reads a whole week with the shared breaks.
