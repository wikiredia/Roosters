Now-board helpers: turn a status code from the API into a line of text, and small lesson lookups.

## `isAway`

Not on campus today: folded together at the bottom of the board.

## `joinNames`

'Lotte, Amir and Ilias' in the current language.

## `nextLesson`, `currentLesson`

The next lesson that takes place, and the one going on now.

## `statusLine`

'Free until 12:30', 'In class until 11:45', …, with whether it counts as free (green). `break_busy` (in a break
but said 'Ik ben bezig', `Checkin.break_status`) is 'Bezig in de pauze' and not free. Used on Vandaag's board and
under a friend's name (profile, chat header).
